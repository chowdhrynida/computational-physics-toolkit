The 1D Ising model, from idea to result.

A chain of magnetic spins, simulated with the Metropolis algorithm. This page walks through it the way the code does — first the physics, then a live run, then the actual output from the repository.

Spins on a line

The 1D Ising model represents a chain of N particles, each holding a spin sᵢ that points either up (+1) or down (−1). Neighbouring spins interact — in the ferromagnetic case, they'd rather point the same way, because that lowers the system's energy.

E = −J Σᵢ sᵢ·sᵢ₊₁ − h Σᵢ sᵢ

J is the coupling strength between neighbours and h is an external magnetic field. With J > 0, aligned neighbours (↑↑ or ↓↓) lower the energy; misaligned neighbours (↑↓) raise it.

How the simulation decides

The code doesn't try every configuration — it uses the Metropolis algorithm: pick a random spin, work out how much the energy would change (ΔE) if it flipped, then:

— if ΔE ≤ 0, flip it (the system likes lower energy)
— otherwise, flip it anyway with probability e^(−ΔE / T)

That second rule is what lets the system explore high-energy states occasionally — exactly as much as temperature allows. Run this over many steps and the chain settles into a realistic thermal equilibrium at temperature T.

Expected behaviour: at low T, spins mostly align — thermal noise is too weak to fight the coupling. At high T, thermal fluctuations win, and spins flip freely — the chain looks disordered.

These four plots are the actual output of the Python script in the repository — the same Metropolis simulation above, but run properly: averaged over many steps, at 100 temperatures from 0.1 to 10. Here's what each one is showing, and why it looks the way it does.

Average energy vs temperature

Near T = 0, energy sits at −1 per spin — every neighbour pair is aligned, the lowest energy the chain can have. As T rises, thermal flips break bonds one by one, so energy climbs toward 0. The curve is steepest right where the order breaks down fastest.

Average magnetisation vs temperature

Starts at 1 — fully aligned — and drops sharply around T ≈ 0.5–1, then trails off toward a small residual value. That drop is the chain losing long-range order as thermal noise overwhelms the coupling between neighbours.

Specific heat vs temperature

Specific heat measures how much the energy fluctuates — C ∝ Var(E)/T². It peaks exactly where the energy curve is steepest, because that's where a small change in T causes the biggest change in how ordered the chain is.

Magnetic susceptibility vs temperature

Susceptibility measures how much the magnetisation fluctuates — χ ∝ Var(M)/T. Like specific heat, it spikes at the same crossover temperature: the chain is most sensitive to small nudges right where it's deciding between order and disorder.

A technical note worth having, since it's easy to over-read this: a true infinite 1D Ising chain (no field, nearest-neighbour only) has no phase transition at any finite T — order always eventually breaks down. What these plots capture is a finite-size, finite-run crossover: with N = 100 spins and a limited number of Monte Carlo steps, the chain behaves as if it has a "critical" temperature, even though the sharp transition itself is a 2D-and-above phenomenon. That's a real and useful thing to see in simulation — just worth naming correctly if this goes in a report.
